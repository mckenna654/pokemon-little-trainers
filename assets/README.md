# assets/

- `generated/v1/`: the illustrated pack (battle buttons, Start menu pictures, title plaque), in the
  game since patch 0034. See [its README](generated/v1/README.md).
- `ui/make_battle_icons.py`: draws the small control symbols and copies the pack's three sheets
  into `game/graphics/little_trainers/`.

Our own source art and working files (layered originals, palettes, mock-ups) for graphics that are
compiled into the game through `patches/`. Third-party assets may only be added after their reuse
terms are recorded in `docs/GRAPHICS.md`. No ripped or ROM-extracted graphics here.
